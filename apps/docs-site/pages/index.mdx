GA4 BigQuery Raw Export Simulator installs a synthetic GA4 raw export dataset
in BigQuery, inside a Google Cloud project you own. The data mirrors a real
GA4 export, and a daily refresh can add new data every day. These pages
explain what it creates, what it costs, how to remove it, and how it works.
