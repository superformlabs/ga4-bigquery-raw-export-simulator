# How to help

Thank you for wanting to. This repository is a one-way copy of a private
working repository, so there is one way in and it is short.

## Pull requests are not accepted

Pull requests are switched off here, and a pull request could not be merged
anyway: the code is written in the private repository and copied here at each
release. The MIT licence lets you fork this repository and change your copy as
much as you like.

## Found a bug? Tell us with the form

[Report a bug](https://github.com/superformlabs/ga4-bigquery-raw-export-simulator/issues/new?template=bug-report.yml).
It is the only kind of issue this repository takes, and we read every one. A
good report says what happened, what you expected, and which page you were on.

**Please do not write private details in an issue.** It is readable by
everyone, now and later. No Google Cloud project ID, no dataset name, no
email address, and no key, token or password. We can act on a report without
them.

## Something private, or not a bug?

Write to support@superformlabs.eu. Use that address for anything that should
not be public, and for questions that are not bug reports.
